RPA Fetch Gmail

RPA Fetch Gmail is an internal automation tool used only by its owner (hgu428@gmail.com).

It runs on the owner's own computers. During automated sign-in to the owner's seller accounts (TikTok Shop, Shopee), it reads the one-time verification code from the owner's own Gmail inbox using the read-only Gmail permission.

The tool is not offered to the public and has no other users.
