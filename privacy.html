Privacy Policy — RPA Fetch Gmail

Last updated: October 19, 2026

Who uses this app

RPA Fetch Gmail is a private automation tool. Its only user is its owner (hgu428@gmail.com). It is not offered to the public.

What data it accesses

With the owner's consent, the app uses the Google API scope https://www.googleapis.com/auth/gmail.readonly. It searches only for recent verification emails from TikTok and Shopee and reads the one-time verification code in them.

How the data is used

The verification code is used immediately to complete the owner's own sign-in to their seller accounts. The app does not modify, send or delete email.

Storage and sharing

  • Email content and verification codes are not stored, logged or transmitted anywhere else.
  • The OAuth token is stored only on the owner's own computers.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
